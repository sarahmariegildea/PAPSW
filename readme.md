# Occupational Trauma and PTSD Among Pennsylvania Public Safety Workers

## Overview

This repository contains the code and reproducible Quarto document for an analysis of occupational trauma exposure, stressors, and PTSD among public safety workers in Pennsylvania.

## Repository Structure

- `PSW_final_project.qmd` - reproducible analysis and report
- `code/` - supporting R scripts
- `Pennsylvania Public Safety Worker Wellness Survey_Codebook 8.10.26.xlsx`- codebook
- `data/` - the data is not publicly available
- `output/` - generated tables and figures

## Reproducibility

To reproduce the analysis:

1.  Clone this repository.
2.  Place the analysis dataset in the `data/` directory.
3.  Open `PSW_final_project.qmd` in RStudio.
4.  Render the document using Quarto.

## Data Availability

The dataset is not included in this repository because it is not a public use dataset.
